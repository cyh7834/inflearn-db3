# 3. 개념적 모델링 --- 요약

## 1. 요구 사항 분석과 핵심 요소 식별

-   개념적 모델링은 시스템이 반영해야 할 현실 세계의 비즈니스를 그림으로
    표현해 이해를 맞추는 단계.
-   요구 사항에서 **명사 → 엔티티/속성**, **동사 → 관계**로 도출.
-   쇼핑몰 요구 사항 분석 결과 주요 엔티티: **회원, 상품, 주문**.

## 2. 엔티티란?

-   데이터를 저장·관리해야 할 유무형의 대상.
-   엑셀 시트와 유사한 개념(시트 = 엔티티, 열 = 속성, 행 = 인스턴스).
-   엔티티의 특징: 업무 관련성, 식별 가능성, 여러 속성 보유, 인스턴스의
    집합, 다른 엔티티와 관계.
