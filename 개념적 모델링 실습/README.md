# 4. 개념적 모델링 - 실습 요약

## 1. 실전 요구 사항 분석

-   실제 온라인 쇼핑몰 구축 프로젝트를 기반으로 실습 진행.
-   초기 기획서에는 방대한 기능이 포함되어 있었고, 이를 그대로 구현하면
    일정 내 개발 불가능.
-   훌륭한 개발자는 기술 중심이 아니라 **비즈니스 중심**으로 접근하여
    핵심 기능을 선별해야 함.
-   기획/사업팀과 논의를 통해 1차 출시(MVP)에 필요한 기능만 추려냄.

## 2. MVP 기능 정의

MVP 기능: 1. 회원 관리
2. 상품 관리
3. 주문
4. 결제
5. 배송

## 3. 핵심 엔티티 도출

-   **회원(Member)**
-   **상품(Product)**
-   **주문(Order)**
-   **결제(Payment)**
-   **배송(Delivery)**

주문과 배송을 분리해 책임을 명확히 하고 관리 단순화.
